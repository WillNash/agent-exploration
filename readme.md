## Core Concepts

### What is A2A?
The **Agent2Agent (A2A) Protocol** is an open standard (Apache 2.0) for enabling AI agents to discover, authenticate, and interoperate with each other — regardless of what framework or vendor built them. It was launched by Google in **April 2025**, contributed to the Linux Foundation in June 2025, and reached **v1.0** in early 2026. As of August 2026, 150+ organisations support it (Google, Microsoft, AWS, Salesforce, SAP, ServiceNow, IBM, etc.).

**A2A vs MCP:** MCP handles agent-to-tool communication. A2A handles agent-to-agent communication. They are complementary.

### The Three Pillars
1. **Agent Card** — machine-readable JSON that an agent publishes at `/.well-known/agent-card.json`, advertising its skills, endpoints, and auth requirements.
2. **Tasks** — stateful units of work with a lifecycle: `submitted → working → input_required → completed / failed / canceled`.
3. **Transport** — HTTP(S) + JSON-RPC 2.0. Three interaction modes:
   - Request/Response (polling)
   - Server-Sent Events (SSE) — streaming
   - Push Notifications (webhook callbacks for long-running tasks)

### Core Actors
| Actor | Role |
|-------|------|
| **User** | Human or automated service initiating requests |
| **A2A Client (Client Agent)** | Initiates A2A communication on behalf of the user |
| **A2A Server (Remote Agent)** | AI agent exposing an HTTP endpoint implementing A2A |

### Data Structures
| Element | Description |
|---------|-------------|
| **AgentCard** | JSON metadata: name, skills, endpoints, auth requirements |
| **AgentSkill** | A single capability the agent exposes |
| **Task** | Stateful work unit with unique `taskId` and `contextId` |
| **Message** | Single communication turn (role: `user` or `agent`) |
| **Part** | Content container: text, file reference, or structured data |
| **Artifact** | Tangible output generated by an agent during task processing |

skill = AgentSkill(

### 4. Define an AgentCard

```python
from a2a.types import AgentCard, AgentCapabilities, AgentInterface

public_agent_card = AgentCard(
    name='Hello World Agent',
    description='Just a hello world agent',
    version='0.0.1',
    default_input_modes=['text/plain'],
    default_output_modes=['text/plain'],
    capabilities=AgentCapabilities(streaming=True, extended_agent_card=True),
    supported_interfaces=[
        AgentInterface(
            protocol_binding='JSONRPC',
            url='http://127.0.0.1:9999',
            protocol_version='1.0'
        )
    ],
    skills=[skill]
)
```

### 5. Implement an AgentExecutor

```python
from a2a.server.agent_execution import AgentExecutor, RequestContext
from a2a.server.events import EventQueue
from a2a.types import TaskState
from a2a.utils import new_agent_text_artifact

class HelloWorldAgent:
    async def invoke(self, query: str) -> str:
        return f"Hello World! You said: {query}"

class HelloWorldAgentExecutor(AgentExecutor):
    def __init__(self):
        self.agent = HelloWorldAgent()

    async def execute(self, context: RequestContext, event_queue: EventQueue):
        # Step 1: Get or create a task
        task = context.current_task
        await event_queue.enqueue_event(task)

        # Step 2: Signal we're working
        await event_queue.enqueue_event(
            TaskStatusUpdateEvent(taskId=task.id, state=TaskState.working)
        )

        # Step 3: Run business logic
        user_query = context.get_user_input()
        result = await self.agent.invoke(user_query)

        # Step 4: Return result as artifact
        await event_queue.enqueue_event(
            TaskArtifactUpdateEvent(
                taskId=task.id,
                artifact=new_agent_text_artifact(result),
                lastChunk=True,
            )
        )

        # Step 5: Mark completed
        await event_queue.enqueue_event(
            TaskStatusUpdateEvent(taskId=task.id, state=TaskState.completed)
        )

    async def cancel(self, context: RequestContext, event_queue: EventQueue):
        raise NotImplementedError("Cancellation not supported")
```

### 6. Start the A2A Server

```python
from a2a.server.request_handlers import DefaultRequestHandler
from a2a.server.routes import create_agent_card_routes, create_jsonrpc_routes
from a2a.server.tasks import InMemoryTaskStore
from starlette.applications import Starlette
import uvicorn

request_handler = DefaultRequestHandler(
    agent_executor=HelloWorldAgentExecutor(),
    task_store=InMemoryTaskStore(),
    agent_card=public_agent_card,
    extended_agent_card=public_agent_card,  # or a more detailed extended card
)

routes = []
routes.extend(create_agent_card_routes(public_agent_card))
routes.extend(create_jsonrpc_routes(request_handler, '/'))

app = Starlette(routes=routes)

if __name__ == '__main__':
    uvicorn.run(app, host='127.0.0.1', port=9999)
```

Run the helloworld sample directly:
```bash
cd samples/python/agents/helloworld
python __main__.py
```

### 7. Interact as a Client (Non-Streaming)

```python
import asyncio
import httpx
from a2a.client import A2ACardResolver, ClientConfig, create_client
from a2a.helpers import new_text_message
from a2a.types import Role, SendMessageRequest

async def main():
    async with httpx.AsyncClient() as httpx_client:
        # Discover agent
        resolver = A2ACardResolver(
            httpx_client=httpx_client,
            base_url='http://127.0.0.1:9999',
        )
        public_agent_card = await resolver.get_agent_card()

        # Create non-streaming client
        config = ClientConfig(streaming=False)
        client = await create_client(agent=public_agent_card, client_config=config)

        # Send a message
        message = new_text_message("Hello agent!", role=Role.ROLE_USER)
        request = SendMessageRequest(message=message)

        async for chunk in client.send_message(request):
            print(chunk)

asyncio.run(main())
```

### 8. Interact as a Client (Streaming)

```python
async def main_streaming():
    async with httpx.AsyncClient() as httpx_client:
        resolver = A2ACardResolver(httpx_client=httpx_client, base_url='http://127.0.0.1:9999')
        agent_card = await resolver.get_agent_card()

        client_config = ClientConfig(streaming=True)
        client = await create_client(agent=agent_card, client_config=client_config)

        message = new_text_message("Stream this!", role=Role.ROLE_USER)
        request = SendMessageRequest(message=message)

        async for chunk in client.send_message(request):
            print(chunk)  # Prints incremental chunks as they arrive

        await client.close()
```

### 9. Multi-Turn Conversations

The server signals `input_required` when clarification is needed. The client continues with the same `taskId` and `contextId`:

```python
# Server side: signal more input needed
await event_queue.enqueue_event(
    TaskStatusUpdateEvent(taskId=task.id, state=TaskState.input_required)
)

# Client side: send follow-up using the same task/context IDs
follow_up = SendMessageRequest(
    message=new_text_message("USD", role=Role.ROLE_USER),
    task_id=previous_task_id,
    context_id=previous_context_id,
)
async for chunk in client.send_message(follow_up):
    print(chunk)
```

## Authentication

A2A delegates authentication to standard HTTP mechanisms. The AgentCard declares security requirements using OpenAPI-compatible security scheme definitions:

- **OAuth 2.0 / OpenID Connect** — most common for production
- **API Keys** — simple header or query param key
- **JWT Bearer tokens** — client obtains token via client-credentials flow, sends in `Authorization: Bearer <token>` header on every request; server validates issuer/audience/expiry/scope
- **mTLS** — mutual TLS for high-assurance scenarios

For development/testing, no authentication is typically configured (open server).

## Gotchas & Warnings

1. **Python 3.10+ required** — the SDK uses modern async features; older versions will fail.
2. **Protocol version compatibility** — SDK v1.0 supports A2A Protocol 1.0 and 0.3 (backward compat mode). Be explicit about `protocol_version='1.0'` in `AgentInterface`.
3. **`uv` vs `pip`** — the SDK officially uses `uv` for dependency management, but plain `pip` + `venv` works fine.
4. **AgentCard URL must be reachable** — the `url` in `AgentInterface` is what clients use to send messages; make sure it matches the actual host/port your server binds to.
5. **`InMemoryTaskStore` is ephemeral** — restarts lose all task state. For production use the `[sql]` extra with a real DB.
6. **Streaming requires declaring capability** — `AgentCapabilities(streaming=True)` must be set in the AgentCard or clients won't attempt SSE.
7. **`extended_agent_card`** — a more detailed card (may include private skills) served at a separate authenticated endpoint. For basic testing, reuse the public card.
8. **`lastChunk=True`** on `TaskArtifactUpdateEvent` — required to signal the end of a streamed artifact; omitting it leaves clients hanging.
9. **contextId vs taskId** — `contextId` groups multiple tasks in the same conversation thread; `taskId` is unique per task. Both are needed for correct multi-turn behaviour.
10. **HTTPS mandatory in production** — the spec mandates TLS for transport security outside of local dev.
